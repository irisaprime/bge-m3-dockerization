# BGE-M3 Antivirus Whitelist

## File Path Exclusions

/var/lib/docker/containers/bge-m3-*
./models/bge-m3/
./models/bge-m3-onnx/
./app/

## File Extension Exclusions

*.onnx      # ONNX model format
*.bin       # PyTorch weights (NOT .exe!)
*.pyc       # Python bytecode

## File Hash Exclusions (RECOMMENDED)

# BGE-M3 model files - see security/checksums.sha256 for full list
# Run: sha256sum models/bge-m3/pytorch_model.bin

## Justification

1. **Source:** Official Hugging Face repos (BAAI/bge-m3)
2. **Verification:** SHA256 checksums match official
3. **Scan:** VirusTotal 0/71 detections
4. **SBOM:** Full provenance in security/sbom-cyclonedx.json
5. **Non-Executable:** Model files are data, not code
6. **Air-Gapped:** No network access

## Verification

# File integrity
sha256sum -c security/checksums.sha256

# File type
file models/bge-m3/pytorch_model.bin
# Expected: data (not ELF, not PE)

# Container scan
trivy image bge-m3:latest
# Expected: 0 CRITICAL

## False Positive Handling

1. Verify checksum: `sha256sum [file]`
2. Submit to VirusTotal: https://www.virustotal.com/
3. Contact AV vendor with this whitelist + SBOM
4. Escalate to security@example.com
